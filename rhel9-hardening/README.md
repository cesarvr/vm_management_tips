## Practical RHEL 9.8 Hardening Guide

This project runs an `Ansible 2.16` conainer using podman and the [ansible-lockdown](https://galaxy.ansible.com/ui/standalone/roles/ansible-lockdown/rhel9_stig/documentation/) playbook to harden the host machine. 
This can become a practical example to run inside Packer or from any other automation pipeline.
